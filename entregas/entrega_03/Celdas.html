0 · Diagrama de Flujo: Cargas, Códigos y Creación de Celdas LED

Flujo hardware actualizado en tiempo real según el píxel (col, row) o celda seleccionada. Muestra las rutas de carga de datos y la extracción del bit LED.

1 · Mapa de posiciones: la pantalla 64×64 son 8×8 celdas

Cada celda guarda el código ASCII de su carácter en la RAM de texto. Dirección: Ram_text = {col[5:3], Row[5:3]} (6 bits → 64 entradas). Haz clic en una celda y escribe una letra.

bits altos [5:3] → celdabits bajos [2:0] → pixel dentro

RAM_text: 64 × 8 bits
ROM_fuentes: 128 caracteres × 8 filas × 8 bits
ROM_addr = {char_code[6:0], Row[2:0]} (10 bits)

2 · Matriz de un carácter: 8 filas × 8 bits

Cada carácter son 8 bytes (uno por fila). El bit 7 es el pixel de la izquierda (Col[2:0]=0) y el bit 0 el de la derecha. Clic en los puntos para dibujar o editar el glifo.
